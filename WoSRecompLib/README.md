# WoSRecompLib

Generated/config layer produced by the XenonRecomp toolchain — analogous to
`UnleashedRecompLib` in [Unleashed Recompiled](https://github.com/hedge-dev/UnleashedRecomp).

```
WoSRecompLib/
├── config/
│   ├── WoS_config.toml           # hand-authored — see docs/02-config-guide.md
│   └── WoS_switch_tables.toml    # generated by XenonAnalyse (not committed until stable)
├── ppc/                          # generated by XenonRecomp — build artifact, gitignored
└── shaders/                      # generated by XenosRecomp (Phase 4+) — gitignored
```

**Nothing under `ppc/` or `shaders/` should be hand-edited.** They're
regenerated from `config/` + your own dumped XEX via
[`tools/recompile.sh`](../tools/recompile.sh). If generated code needs a
behavioral fix, the fix belongs in the config (a `functions[]` override, a
mid-asm hook) or in the `WoSRecomp/` runtime — not as a hand-patch to
generated output, which would be silently lost on the next regeneration.
